# Veggie Prep Android screenshot gallery

Captured from the native app on an Android 16 (API 36) medium-phone emulator
at 1080 x 2400. Pantry and recipe content is sample data. Screens 1–12 use a
local mock OpenAI-compatible service. Screens 14–21 include a live suggestion
from the owner's self-hosted Qwen 3.6 endpoint; no third-party AI provider
received the sample pantry data. Screens intended for public release do not
display the private endpoint address.
