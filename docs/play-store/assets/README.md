# Play Store graphics

- `app-icon.png` — 512 x 512 Play Store icon
- `feature-graphic.jpg` — 1024 x 500 feature graphic
- `phone/` — portrait phone screenshots fitted to Play Store-compatible
  1080 x 1920 dimensions

The live Qwen meal screenshots numbered 14–21 omit the owner's private
self-hosted API address and are safe candidates for the store listing. The
strongest feature sequence is 17 (regional alias search), 18 (expiry rescue),
19 (shopping gaps), 21 (cooked status), and 20 (updated pantry).

The SVG files are editable design references. Regenerate the final icon with
`../render_app_icon.swift`, then regenerate the feature graphic with
`../render_feature_graphic.swift`.
